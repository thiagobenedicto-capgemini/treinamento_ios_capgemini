# To-Do List com SwiftUI e MVVM

Exercício prático de lista de tarefas para iOS, desenvolvido com SwiftUI e a arquitetura MVVM.

## Funcionalidades

- Adicionar tarefas digitando um título.
- Ver as tarefas cadastradas.
- Marcar e desmarcar tarefas como concluídas.
- Excluir tarefas arrastando a linha para o lado (swipe-to-delete).
- Impedir a criação de tarefas com títulos vazios ou apenas espaços.
