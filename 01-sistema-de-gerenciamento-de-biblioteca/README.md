# Sistema de Gerenciamento de Biblioteca

Aplicação de linha de comando desenvolvida em Swift para um exercício do Curso de IOS @ Capgemini - Turma 2.

Permite cadastrar, listar, buscar, editar e remover livros, além de controlar seu status de empréstimo. As buscas podem ser realizadas por ID ou por título completo ou parcial.

O projeto utiliza protocolo, classe, encapsulamento e um array para armazenar os livros durante a execução. A interação ocorre pelo console, por meio de um menu numérico.
