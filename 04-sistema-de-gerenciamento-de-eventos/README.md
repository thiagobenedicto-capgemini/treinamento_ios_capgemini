# Gerenciador de Eventos — SwiftUI + SwiftData + MVVM

Projeto de acompanhamento do Programa de Formação iOS — Capgemini & Ready Proway.

## Funcionalidades implementadas

- Cadastro de evento com título, descrição, data/hora e local.
- Validação de campos vazios ou preenchidos apenas com espaços.
- Exclusão de eventos deslizando a linha para a esquerda.
- Persistência local com SwiftData (os dados devem permanecer após fechar e abrir o aplicativo).
